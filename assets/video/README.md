# Invitation Film (Optional)

To enable the "Watch the Invitation Film" modal:
1. Place your video file at `assets/video/invitation.mp4` (or configure a custom URL in `config.js`).
2. Set `showInvitationFilm: true` in `config.js`.

When active:
- A royal button appears on the Baraat & Pheras ceremony card.
- Clicking opens a high-definition cinematic video modal.
- Background instrumental music automatically pauses while the film is playing and resumes when closed.
